3-Tier + MVC Architecture & Boundary Rules

V · View Tier
com.habitflow.ui
JavaFX 21 desktop screens, dialogs, custom heatmap canvas, and CSS. Only App is public; every screen is package-private.
Rule: Talks ONLY to controllers in AppContext. Never imports com.habitflow.db or java.sql.
→
C · Controller Tier
com.habitflow.controller & .logic
Use-case orchestration, transactions, Session, achievements, reminders, CSV I/O, and 5 pure calculation modules.
Rule: Zero SQL and zero JavaFX imports. Calls DAOs and wraps multi-step writes in Database.inTransaction().
→
M · Database Tier
com.habitflow.db + PostgreSQL
The ONLY package with SQL. Single synchronized JDBC connection in Database + BaseDao<T> template + 11 DAOs over 14 tables.
Rule: Never imports controller or ui. Database.with() is package-private so SQL cannot leak upward.
M · Shared Domain Model com.habitflow.model Pure Java entities, value records, enums, and OOP hierarchies shared by all 3 tiers. Zero SQL, zero JavaFX.

How Each Layer Works (M, V, and C)

M · Model & DB Model + DB + SQL

Model & Data Persistence

Owns the domain model (model/), PostgreSQL schema (schema.sql), and all 11 JDBC DAOs (db/).

  • Read first:
  • Core OOP: Person, Habit, Schedule / DayBasedSchedule, PowerUp, BaseDao<T>.
  • Contract with C: Keeps model/ 100% pure Java, keeps Database.with() package-private, and parameterizes all SQL via BaseDao.
V · View JavaFX Views + CSS

View & Desktop GUI

Owns all 11 JavaFX screens/dialogs (ui/), the custom 365-day HeatmapCanvas, and styles.css.

  • Read first:
  • Core OOP: Abstract Page + 9 subclasses, package-private encapsulation (only App is public).
  • Contract with C: Calls controllers only through ctx (AppContext) and wraps actions in Ui.attempt(...) so validation errors show clean alerts.
C · Controller Controllers + Logic

Controllers & Business Logic

Owns use-case controllers (controller/) and pure algorithms (controller/logic/) connecting View to Model/DB.

  • Read first:
  • Core OOP: Overloading (checkIn, completionRate, StrengthScore.compute), Observer (CheckInListener), inner adapter (ShopController.Context).
  • Contract with V & M: Zero JavaFX or java.sql imports; validates inputs, wraps multi-table writes in Database.inTransaction(), and calls Session.refresh() when coins change.
